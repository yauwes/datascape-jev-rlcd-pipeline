4. DATASET STRUCTURE & AUDITED TRAINING DATA INFORMATION
--------------------------------------------------------------------------------
Only official competition data provided by the committee is used:
- Dataset Root Directory : `datascape/`
  ├── Train_Set/
  │   ├── Aman/          (8,800 images)
  │   ├── Lainnya/       (423 images)
  │   └── Rusak/         (3,001 images)
  ├── Test_Set/          (3,057 test images)
  └── sample_submission.csv (3,057 rows)

Audit Temuan Data Latih (Internal Training Data Audit):
1. Pergeseran Resolusi (Covariate Shift):
   - Citra berukuran 224x224 mencakup hanya 2.1% data train, namun melonjak menjadi 17.0% data test (seluruhnya merupakan paket utuh 'Aman').
   - Citra berukuran 675x900 mencakup 4.1% train dan 9.2% test.
2. Anomali Label Duplikat Kontradiktif:
   - Terdeteksi 122 pasang citra bit-identik di data latih yang memiliki label kontradiktif (112 pasang Aman vs Rusak, 10 pasang Aman vs Lainnya) akibat noise anotasi crowdsourcing.
   - Hash metadata dan audit mask tersimpan pada: `work/emb/meta_sorted.csv` dan `work/meta_noise.csv`.
3. Deteksi Label Noise via Confident Learning (Cleanlab):
   - Sebanyak 437 sampel pada data latih teridentifikasi memiliki label bermasalah dengan probabilitas OOF tinggi.
4. Klasterisasi Bebas Kebocoran (Leak-Free Group Fold):
   - Pembagian 5-fold StratifiedGroupKFold berdasarkan kesamaan DINOv2 (cosine >= 0.90) menghasilkan 850 klaster independen (`work/folds_group90.csv`), mencegah kebocoran citra kembar antar fold.


5. PANDUAN MENJALANKAN ULANG NOTEBOOK (RE-RUN INSTRUCTIONS)
--------------------------------------------------------------------------------
Langkah 1: Kloning repositori proyek atau buka folder root proyek:
   $ git clone https://github.com/yauwes/datascape-2026-pipeline.git
   $ cd datascape-2026-pipeline

Langkah 2: Buat dan aktifkan virtual environment Python:
   $ python3.11 -m venv venv
   $ source venv/bin/activate    # Linux / macOS
   # atau: venv\Scripts\activate # Windows

Langkah 3: Pasang paket dependensi:
   $ pip install -r NamaTim_Requirements_Datascape.txt

Langkah 4: Jalankan notebook Jupyter:
   $ jupyter notebook NamaTim_Notebook_Datascape.ipynb

Langkah 5: Eksekusi seluruh sel notebook:
   Pilih menu: "Kernel" -> "Restart & Run All".

Notebook akan secara berurutan menjalankan:
1. Audit Eksplorasi Data (EDA), distribusi kelas, dan pergeseran dimensi citra.
2. Analisis duplikat dihedral (NCC 8-arah) dan visualisasi pasangan berlabel kontradiktif.
3. Desain validasi bebas kebocoran (StratifiedGroupKFold 5-fold).
4. Evaluasi model ensemble multi-tower (OOF macro F1, confusion matrix, classification report).
5. Audit label noise dengan Cleanlab Confident Learning.
6. Transfer label kembaran via SSCD twin lock dan domain-adapted heads (reproduksi d04_da_bt2).
7. Eksperimen probe berpasangan (reproduksi d05_p416_allA dan d05_p675_R).
8. Pseudo-labeling transduktif iteratif dengan evaluasi domain uji held-out.
9. Pemeringkatan eksperimen terstruktur.
10. Regresi leaderboard terbukti (reproduksi bit-identik d11_lbopt, skor PB 0.88891).
11. Analisis bukti fisik blob ratio citra 416x416.
12. Trajektori ekspektasi vs realita leaderboard dari seluruh submission resmi.
13. Rekonstruksi konsensus submission d08 dan pembuatan file final di folder `notebook/output/`.

Estimasi Waktu Eksekusi:
- Mode default (reproduksi instan & verifikasi assert bit-identik): ~15–30 detik.
- Mode retrain penuh dari fitur embedding (DS_RETRAIN=1): ~2–10 menit tergantung GPU.
